# SDLC, Agile, and Scrum

Practice app: [browser Todo List](../todo-list/).

| Exercise | Deliverable |
| --- | --- |
| User stories | [10 user stories with acceptance criteria](docs/requirements.md) |
| Project board | [Todo List board](https://github.com/users/LaZy-Wolf/projects/1/views/1) |
| SDLC model comparison | [Waterfall and Agile](docs/sdlc-notes.md) |

The board has four columns. **Backlog** holds planned work, **In Progress** holds work underway, **Review** holds items ready for acceptance checks, and **Done** holds items that meet their criteria.
